# SQL

I have used SQL extensively for querying and extracting data in **Google BigQuery**, supporting reporting, analysis, and insight generation across structured datasets.

My experience includes:

- **Filtering and data extraction** using `WHERE`, `IN`, `BETWEEN`, and date-based filters
- **Aggregations** using `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`
- **Conditional logic** using `CASE WHEN` statements for segmentation and classification
- **Data cleaning and transformation** using functions such as `REGEXP_REPLACE`, `TRIM`, `CAST`, and string manipulation techniques
- **Joins** for combining data across multiple sources
- **Basic window functions**, including `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()` for ranking, ordering, and segmentation
- **Subqueries and common business reporting logic** for identifying trends, exceptions, and performance metrics

While I would not describe myself as an advanced SQL developer, I am comfortable writing, understanding, and adapting queries within a governed enterprise data environment and can work independently on typical data analysis and reporting requirements.
